# Prates a conhecer

Portfólio digital de Psicologia do Desenvolvimento da Criança — UFBA.

A primeira versão contém:

- loading screen;
- hero experimental;
- fotografias flutuantes;
- prólogo narrativo;
- primeiro capítulo;
- microinterações;
- cursor customizado;
- estrutura para áudio e vídeo;
- seção de releitura acadêmica;
- preparação para os quatro momentos do desenvolvimento.

As fotografias e relatos reais serão substituídos/adicionados durante a construção do portfólio.

## Publicação

O repositório já contém um workflow para GitHub Pages. Em **Settings → Pages**, selecione **GitHub Actions** como fonte, caso o Pages ainda não esteja ativado.
